# Agent Orchestrator

Coordinates specialized domain agents to prevent monolithic prompting and ensure isolated, verifiable task execution.

## Managed Agents
- **Roadmap Synthesis Agent:** Deconstructs role benchmarks into milestone DAGs.
- **Daily Planner Agent:** Compiles achievable daily checklists based on user velocity.
- **Technical Interview Evaluator:** Multi-rubric code, audio, and reasoning assessor.
- **Adaptive Career Mentor:** Contextual chat assistant acting as a senior staff engineer.
