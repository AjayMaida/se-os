# AI Subsystem Overview

The SE-OS AI Platform provides autonomous, context-aware intelligence spanning career roadmap synthesis, daily task scheduling, real-time code execution analysis, and multi-dimensional interview assessment.

## Key Capabilities
- **Adaptive Execution:** Continuous recalculation of learning paths based on daily velocity and assessment feedback.
- **Provider Agnostic:** Dynamic model routing between OpenAI, Anthropic, Google, and self-hosted models.
- **Microservice Isolation:** Dedicated FastAPI AI service decoupled from the relational CRUD API.
