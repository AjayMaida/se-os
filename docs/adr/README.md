## 📝 ADR Template

When authoring a new ADR, use the following structure:
1. **Title:** Short noun phrase with sequential ID (e.g. `ADR-0003-piston-sandbox-execution.md`)
2. **Status:** `Proposed`, `Accepted`, `Rejected`, or `Superseded`
3. **Context:** What business or technical challenge are we solving?
4. **Decision:** What solution was chosen and why?
5. **Consequences:** Positive and negative trade-offs of this decision.
